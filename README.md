# Boltz TV Setup

TV mounting business website for Bentonville, Arkansas.

Run `npm run build`, `npm run check`, then `npm run dev` with Node.js 22 or newer. No dependencies are required. Source files and assets are in the repository root; the build creates all ten pages in `dist/`.

Set `SITE_BASE_PATH` to the hosting subdirectory and `SITE_ORIGIN` to the host origin when building. The estimator is browser-only and does not submit inquiries or reserve appointments. Optional-service prices still require owner confirmation.
