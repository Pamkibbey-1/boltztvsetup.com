# Website assets

The current website uses four installation photographs supplied by the user. They were copied without visual editing. The gallery opens each complete image so before-and-after details remain visible.

| Website asset | Supplied file | Use |
| --- | --- | --- |
| `dist/assets/work-living-room.png` | `mt-4.png` | Home hero, gallery and general service imagery |
| `dist/assets/work-fireplace.jpg` | `mt-3.jpg` | Our Work and fireplace service page |
| `dist/assets/work-cable-cleanup.png` | `mt-2.png` | Our Work, cable service page and home service introduction |
| `dist/assets/work-tv-mounting.webp` | `mt-1.webp` | Our Work before-and-after photo |

No customer names, installation dates, project locations, ratings or review counts have been invented for these photographs.

The TV-and-wall-bracket logo, favicon and interface icons are SVG assets. Reusable logo files are `dist/assets/logo.svg` and `dist/assets/logo-mark.svg`.

Typography uses DM Sans and Manrope from Google Fonts with local sans-serif fallbacks. This font request is described in the privacy information.
